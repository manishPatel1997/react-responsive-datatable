# Contributing to react-responsive-datatable

Thank you for your interest in contributing to `react-responsive-datatable`!

## Development Workflow

1. Clone the repository:
   ```bash
   git clone https://github.com/UDAN/react-responsive-datatable.git
   cd react-responsive-datatable
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the interactive dev server:
   ```bash
   npm run dev
   ```

4. Run tests:
   ```bash
   npm test
   ```

5. Build library distributions:
   ```bash
   npm run build:lib
   ```

## Pull Request Guidelines

- Ensure tests pass with `npm test`.
- Verify the build succeeds with `npm run build && npm run build:lib`.
- Write unit tests for new features or bug fixes.
- Follow existing code formatting conventions.
